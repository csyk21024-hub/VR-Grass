# VR-Grass

VRグラスを用いた建築アプリケーションの可能性を探求するプロジェクトです。

## 概要

本プロジェクトでは、VR（バーチャルリアリティ）グラスを活用した建築分野でのアプリケーションについて、その可能性と将来性を探ります。

## VRグラスを用いた建築アプリの可能性

### 1. バーチャル建築モデルの可視化

- **3Dウォークスルー**: 設計段階の建物内を実際に歩いているかのように体験
- **スケール感の確認**: 実寸大で空間の広さや高さを体感
- **素材・質感の確認**: 壁材、床材、照明効果などをリアルタイムでプレビュー

### 2. クライアントとのコミュニケーション

- **設計提案のプレゼンテーション**: 図面だけでは伝わりにくい空間イメージを共有
- **リアルタイム修正**: その場で色や素材を変更して確認
- **遠隔コラボレーション**: 離れた場所にいる関係者と同じ仮想空間で打ち合わせ

### 3. 設計・施工の効率化

- **設計ミスの早期発見**: 施工前に問題点を3D空間で確認
- **施工シミュレーション**: 工程の可視化と安全教育への活用
- **BIM連携**: Building Information Modelingとの統合による設計データの活用

### 4. 教育・トレーニング

- **建築学習**: 歴史的建造物や名建築のバーチャルツアー
- **施工技術訓練**: 危険を伴う作業の安全なシミュレーション
- **インテリアデザイン学習**: 家具配置や色彩設計の練習

### 5. 不動産・住宅販売

- **バーチャル内覧**: 建設前の物件や遠方の物件をVRで確認
- **カスタマイズ体験**: 購入者が間取りや仕上げをその場で変更
- **家具配置シミュレーション**: 入居前に家具の配置を検討

## 主要なVRデバイス

| デバイス | 特徴 | 建築用途での利点 |
|---------|------|-----------------|
| Meta Quest 3 | スタンドアロン型、MR対応 | 持ち運びやすく現場での使用に適する |
| Apple Vision Pro | 高解像度、空間コンピューティング | 精細な設計レビューに適する |
| HTC VIVE Pro 2 | 高解像度、PC接続型 | 大規模プロジェクトの詳細なレビュー |
| PlayStation VR2 | コンシューマー向け | 一般向けの住宅プレゼンテーション |

## 技術的な考慮事項

### 開発プラットフォーム

- **Unity**: 豊富なVRプラグインとアセット
- **Unreal Engine**: 高品質なグラフィックスとリアルタイムレンダリング
- **WebXR**: ブラウザベースでアクセシブルなVR体験

### データ形式

- **IFC (Industry Foundation Classes)**: BIMデータの標準形式
- **glTF/GLB**: 3Dモデルの軽量な転送形式
- **FBX**: 汎用的な3Dデータ交換形式

## 今後の展望

1. **AI統合**: AIによる設計提案やリアルタイムレンダリングの高速化
2. **触覚フィードバック**: 素材の触感をシミュレート
3. **クラウド連携**: 大規模なBIMデータのストリーミング
4. **サステナビリティ分析**: 環境負荷のリアルタイム可視化
